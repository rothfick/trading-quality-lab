## Problem and behavior

An independent quality lab needs a reproducible first signal and explicit boundaries before expanding test tooling. This increment pins OpenAlgo, exercises its real order schema with five non-crypto quantity examples, and proves sensitivity to a weakened zero boundary through an isolated temporary mutation.

## Implementation

- Separate uv environment, source/hash manifest and bootstrap/test/prove/doctor entry points.
- Read-only GitHub Actions workflow with pinned action revisions and JUnit/JSON evidence artifacts.
- Strategy v0, source audit, risk/competency maps, roadmap, two ADRs and an iteration workshop.

## Validation

Local lint and formatting checks pass. The unmodified schema passes five examples; the mutant fails exactly the zero-quantity case. See the iteration report for clean-checkout and fail-closed verification. Hosted CI is pending publication and must be checked on this PR.

## Limits and handoff

This is a schema component test, with no HTTP, authorization, persistence, market feed or trading execution. It is one sensitivity proof, not a mutation coverage score. Local-model infrastructure remains planned. The workshop is in `quality-lab/docs/iterations/001-foundations.md`; learner review and the exercise remain human follow-up work.
