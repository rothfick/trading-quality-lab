# Local AI lifecycle work

Planned: local assistance for requirements analysis, test design, exploratory guidance, triage and report drafting. No local model is installed or invoked by iteration 01.

Before adoption, benchmark a pinned local model against reviewed tasks and a non-AI baseline. Record prompts, parameters, inputs, quality, latency, review effort and hallucinations. Treat documents/logs as untrusted data, evaluate prompt injection, validate structured outputs and keep release decisions independent of model output.
